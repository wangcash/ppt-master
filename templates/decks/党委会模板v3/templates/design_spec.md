# 党委会模板v3 — Design Specification

## I. Template Overview

| Application context | Definition |
|---|---|
| Recurring presentation family | 公司各部门向党委会 / 党委常委会进行工作汇报、事项审议、前置研究和情况报告等会议材料。 |
| Intended audiences and outcomes | 党委委员 / 党委常委；支持审议决策、情况通报与工作部署。 |
| Delivery and reading assumptions | 以会议室投屏宣讲为主，兼顾会后传阅；正文以清晰可读的 16–24px 级字号为主。 |
| Representative narrative/page roles | 封面、前言、目录、章节页、默认空白页、图文混排（左文右图 / 上文下图）、重点强调、大段文本高亮、要点分栏、修订对比（无图 / 单图 / 多图）、数据指标卡、结束页。 |

整体为白底红色党政视觉：以 `#C00000` 为主色，封面/结束页使用深红横幅，内容页以红色标题条统一识别，灰白面板承载正文，红色用于关键数据、核心结论与高亮强调。

## IV. Signature Design Elements

- 封面/结束页：全宽深红横幅（`#B5261F`）横贯画面中部，承载反白标题，形成首尾呼应的固定品牌幕布；结束页文字为固定内容“汇报完毕”。
- 前言/目录页：灰白渐变圆角卡片 + 左上红色折角标 + 大号页面标签；卡片带轻微投影，右下角红色折角为识别点。
- 章节页：居中红色菱形叠加灰边菱形，白色序号居中，红色章节标题两侧配细线。
- 默认空白页：红色标题条 + 浅灰内容底板 + 底部右侧品牌 Logo，正文区可留空或填内容。
- 图文混排页（左文右图）：红色标题条 + 左侧正文 + 右侧两个图片位（一主一辅），图片统一中性占位图。
- 图文混排页（上文下图）：红色标题条 + 上部正文 + 下方通栏图片位。
- 重点强调页：红色标题条 + 左侧红色竖条 + 大号核心结论/数据（红）+ 支持性说明。
- 大段文本高亮页：红色标题条 + 浅灰底板 + 大段正文 + 底部浅红（`#FDE7E7`）高亮条承载红色加粗关键句。
- 要点分栏页：红色标题条 + 两个红色方块标 + 左右两栏要点（红标题 + 灰正文）。
- 修订对比页：红色标题条 + 浅灰底板 + 左右两个红框双栏，红色栏标题（如“修订前 / 修订后”）。
- 修订对比页（单图，左文右图）：左侧双栏红框 + 右侧单个图片位。
- 修订对比页（多图，上文下图）：上部双栏红框 + 下方 2–3 个图片位横排。
- 数据指标卡页：红色标题条 + 四张浅灰圆角卡片，每卡大号红色数字 + 指标名 + 说明。
- 布局栅格：页面左右安全边距约 76px，标题条高约 38.67px，正文底板从标题条下方约 124px 开始。
